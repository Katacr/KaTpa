# User Guide

KaTpa provides two teleport directions and lets every player choose their preferred request response method.

* [Teleport Requests](requests.md): sending, accepting, denying, canceling, and the teleport warm-up
* [Personal Settings](settings.md): dialog, chat, double-sneak modes, and list management

For a quick start, run `/tpa` or `/tpahere` and choose a target from the player dialog.
