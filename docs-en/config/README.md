# Server Configuration

Server owners can adjust request expiration, teleport warm-up, cooldowns, world restrictions, sounds, particles, and language.

* [Functional Settings](config.md): single-server and general settings
* [Cross-Server Teleportation](proxy.md): using KaTpa on a Velocity or BungeeCord network

Back up `plugins/KaTpa/config.yml` before editing it. Regular settings can be applied with `/katap reload`; database changes require a server restart.
