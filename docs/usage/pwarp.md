# 玩家地标

玩家可以创建属于自己的公共地标，其他玩家能够浏览全部地标、传送并评分；创建者可获得他人传送时支付的费用。

> 玩家地标与管理员地标（`/warp`）相互独立：玩家地标由普通玩家创建，管理员地标由 `katpa.warp.admin` 管理。

## /pwarp — 浏览与传送

```text
/pwarp
/pwarp <名称>
```

不带名称时打开玩家地标选择列表，列出服务器上全部玩家地标（含创建者、描述、图标、平均星级与得分）。带名称时直接传送到指定玩家地标。

列表中的操作：

* **左键** 传送（创建者本人免费，他人按地标设置的 `cost` 付费）
* **右键** 打开评分菜单（1-5 星）
* 菜单按钮 **B**（我的地标）打开自己创建的地标管理列表
* 菜单按钮 **L**（排行榜）打开评分前十的玩家地标排行榜

## 创建自己的地标

```text
/katap pwarp create <名称>
```

在当前位置创建玩家地标。可创建的数量上限由权限 `katpa.pwarp.amount.<n>` 控制（默认 1）。

## 管理自己的地标

打开「我的地标」列表（或 `/pwarp` 后点 **B**），点击地标即可打开编辑器，可修改：

* **名称**：`/katap pwarp rename <旧名称> <新名称>`
* **描述**：编辑器内 D 按钮，或 `/katap pwarp set desc <名称> <文本>`
* **费用**：编辑器内 F 按钮，或 `/katap pwarp set cost <名称> <金额>`
* **冷却**：编辑器内 C 按钮，或 `/katap pwarp set cooldown <名称> <秒>`
* **图标**：编辑器内 I 按钮（手持物品点击设置，支持材质、`custom_model_data`、1.21.4+ 的 `item_model`）

删除自己的地标：`/katap pwarp delete <名称>`。

## 评分与排行榜

任意玩家可对任意玩家地标评 1-5 星（右键地标或 `/katap pwarp rate <名称> <1-5>`）。得分按权重累加：

| 星级 | 得分 |
| --- | --- |
| 5★ | +10 |
| 4★ | +5 |
| 3★ | +1 |
| 2★ | -5 |
| 1★ | -10 |

排行榜（`/pwarp` 后点 **L**）按累计加权得分降序展示前十地标，含排名、创建者、描述、平均星级与传送费用。每个玩家对同一地标只能评一次，重复评分会覆盖上次。

## 传送收入

其他玩家传送你的地标时，按该地标设置的 `cost` 向你支付费用：

* 你在线时费用直接入账（需安装 Vault 经济插件）。
* 你离线时（可能在其他子服或完全不在线），费用计入离线挂账，待你**下次上线任意子服**时自动领取并提示。

未安装 Vault 时费用设置被忽略，玩家免费传送，也无收入结算。

## 管理员清理

拥有 `katpa.pwarp.admin` 的管理员可以编辑或删除任意玩家地标，用于清理无意义或违规地标：

```text
/katap pwarp delete <名称>
/katap pwarp edit <名称>
```
