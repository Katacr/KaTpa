# 玩家地标

玩家可以创建属于自己的公共地标，其他玩家能够浏览全部地标、传送并评分；创建者可获得他人传送时支付的费用。

> 玩家地标与管理员地标（`/warp`）相互独立：玩家地标由普通玩家创建，管理员地标由 `katpa.warp.admin` 管理。

## /pw 与 /pwarp — 浏览与传送

```text
/pw <名称>      # 快捷传送（按名）
/pwarp          # 打开排行榜
/pwarp <子命令> # leaderboard / favorites / mine / history / admin
```

* `/pw <名称>` 直接按名传送到指定玩家地标（创建者本人免费，他人按 `cost` 付费；收费时会先弹出可点击的二次确认）。
* `/pwarp` 不带参数打开**排行榜**。
* `/pwarp leaderboard`（别名 `top`/`rank`）打开排行榜。
* `/pwarp favorites`（别名 `favorite`/`fav`）打开我的收藏。
* `/pwarp mine`（别名 `my`/`manager`）打开我的地标管理列表。
* `/pwarp history`（别名 `his`）打开历史传送列表。

玩家地标列表（主列表、历史、收藏、玩家筛选、排行榜）中的条目操作统一为：

* **左键** 传送
* **右键** 评分（打开 1-5 星评分菜单）
* **Q 键**（丢弃键）收藏 / 取消收藏

> 「我的地标」管理列表中的条目仍为**左键/右键编辑**，保留 GUI 编辑入口。

## 收费确认

当目标地标设置了传送费用且你不是创建者时，`/pw <名称>` 会先发送一条可点击消息：

```text
传送点 <名称> 传送费用为 <金额> 金币，继续传送吗？ [确定] [取消]
```

点 **[确定]** 才扣除费用并传送，点 **[取消]** 放弃（消息 30 秒后失效）。

## 传送冷却

玩家地标传送设有**全局冷却**（`modules.pwarp.cooldown-seconds`，默认 30 秒），按**每个玩家**独立计时：冷却期间该玩家不能再次使用 `/pwarp`/`/pw` 传送（会提示剩余秒数），换一个地标也一样要等待。设为 `0` 表示不冷却。

> 该冷却与地标无关，因此地标编辑器不再提供单独的冷却设置。

## 历史传送

打开「玩家地标」列表后点 **H**，列出你**曾经成功传送过**的玩家地标（按最近访问倒序，去重）。点击项可再次传送，右键收藏/取消收藏。

## 按玩家筛选

打开「玩家地标」列表后点 **P**，列出服务器上所有**拥有至少一个玩家地标**的创建者（按名称排序）。点击某个玩家进入其全部地标的筛选视图，可传送与收藏。

## 收藏

玩家可手动收藏感兴趣的玩家地标：

* 在「玩家地标」主列表、历史列表、玩家筛选列表中，按 **Q 键**（丢弃键）即可收藏 / 取消收藏。
* 打开「我的收藏」列表（**F**），列出全部已收藏地标，按 Q 键取消收藏，左键传送。

## 创建自己的地标

```text
/katap pwarp create <名称>
/pwarp admin edit <名称>   # 打开任意地标的编辑器（管理员）
```

在当前位置创建玩家地标。可创建的数量上限由权限 `katpa.pwarp.amount.<n>` 控制（默认 1）。若配置了创建费用（见下），创建时会按所选货币扣费，余额不足则创建失败。

### 创建费用（可选）

`config.yml` 的 `modules.pwarp.create-cost` 可要求创建玩家地标消耗金币或点券（二选一）：

```yaml
modules:
  pwarp:
    create-cost:
      currency: money   # money = Vault 金币；points = PlayerPoints 点券
      money: 0          # currency=money 时的金币金额
      points: 0         # currency=points 时的点券数量
```

* 金额为 `0` 或对应前置（Vault / PlayerPoints）未安装时不收费。
* 点券需服务器安装 **PlayerPoints**（可选前置，未安装时自动忽略）。

## 管理自己的地标

打开「我的地标」列表（`/pwarp mine`），左键或右键地标即可打开编辑器，可修改：

* **名称**：`/katap pwarp rename <旧名称> <新名称>`
* **描述**：编辑器内 D 按钮，或 `/katap pwarp set desc <名称> <文本>`
* **费用**：编辑器内 F 按钮，或 `/katap pwarp set cost <名称> <金额>`
* **更新位置**：编辑器内 U 按钮（将地标位置更新为你当前所在位置）
* **图标**：编辑器内 I 按钮（手持物品点击设置，支持材质、`custom_model_data`、1.21.4+ 的 `item_model`）
* **删除**：编辑器内 R 按钮（创建者本人删除）；管理员还会看到 Q 按钮（强行删除）

删除自己的地标：编辑器内 **R** 按钮，或 `/katap pwarp delete <名称>`。

## 管理员清理

拥有 `katpa.pwarp.admin` 的管理员可以编辑或删除任意玩家地标，用于清理无意义或违规地标。在任意玩家地标的编辑器（「我的地标」列表内打开）中，管理员会额外看到 **Q（管理员强行删除）** 按钮，可无视创建者直接删除；也可使用指令：

```text
/pwarp admin edit <名称>     # 打开任意地标的编辑器
/pwarp admin delete <名称>   # 强行删除任意地标
/pwarp admin reload          # 仅重载地标数据并重算排行榜缓存
```

`/pwarp admin reload` 只重新读取玩家地标数据并重算排行榜缓存，不会重载配置、语言或菜单（如需重载这些请用 `/katap reload`）。

## 评分与排行榜

任意玩家可对任意玩家地标评 1-5 星（右键地标或 `/katap pwarp rate <名称> <1-5>`）。得分按权重累加：

| 星级 | 得分 |
| --- | --- |
| 5★ | +10 |
| 4★ | +5 |
| 3★ | +1 |
| 2★ | -5 |
| 1★ | -10 |

排行榜（`/pwarp`）按累计加权得分降序展示前 `modules.pwarp.leaderboard-cache-size`（默认 30）名地标，含排名、创建者、描述、平均星级与传送费用。每个玩家对同一地标只能评一次，重复评分会覆盖上次。

排行榜结果由缓存提供：创建、删除玩家地标或评分成功时自动重算，也可用 `/pwarp admin reload` 手动重算；跨服环境下变更会广播给其他子服同步刷新。

## 传送收入

其他玩家传送你的地标时，按该地标设置的 `cost` 向你支付费用：

* 你在线时费用直接入账（需安装 Vault 经济插件）。
* 你离线时（可能在其他子服或完全不在线），费用计入离线挂账，待你**下次上线任意子服**时自动领取并提示。

未安装 Vault 时费用设置被忽略，玩家免费传送，也无收入结算。

## 世界黑名单

`config.yml` 的 `modules.pwarp.disabled-worlds` 可配置**禁止传送到的世界名称**（区分大小写）。目标世界在黑名单中时 `/pw`、`/pwarp` 会被拒绝；玩家处于黑名单世界时也无法创建或更新玩家地标。
