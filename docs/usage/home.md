# 个人家

每名玩家可以设置自己的个人家位置，通过 `/home` 快速传送回家。

## /home — 传送到家

```text
/home
/home <名称>
```

不带名称时打开家选择对话框，列出当前可用的全部家。带名称时直接传送到指定家。

在家列表中**右键**某个家会打开该家的编辑器，可以修改图标、更新位置或删除（详见下文「家编辑器」）。每个家可以单独设置描述与图标（通过家管理 GUI）：

* **描述**：在家列表中展示的说明文字
* **图标**：列表与编辑器中展示的物品（支持材质、`custom_model_data` 与 1.21.4+ 的 `item_model`）

## 家编辑器

在家列表（`/home` 或 `/sethome` 管理对话框）中右键某个家即可打开该家的编辑器，提供三个功能：

* **图标**：手持任意物品点击「图标」按钮，将该物品设为家的图标。
* **更新位置**：将家的位置更新为玩家当前所在位置（保留描述与图标）。
* **删除**：删除这个家。

## /sethome — 创建或管理家

```text
/sethome
/sethome <名称>
```

不带名称时打开家管理对话框，可以查看全部家、删除家或创建新家。带名称时以当前位置创建或更新家。列表中右键某个家同样会打开家编辑器。

## /delhome — 删除家

```text
/delhome <名称>
```

删除指定家。不带名称时打开管理对话框。

## 家数量上限

默认可设置 1 个家。通过权限插件授予以下权限可增加数量：

| 权限 | 可设置数量 |
| --- | --- |
| `katpa.home.amount.1` | 1（默认） |
| `katpa.home.amount.3` | 3 |
| `katpa.home.amount.5` | 5 |
| `katpa.home.amount.10` | 10 |

玩家同时持有多个该权限时取最大值。

## 跨服回家

启用 `proxy.enabled` 后，`/home` 可以跨服回家。如果目标家在其他子服，KaProxy 会自动切换服务器并传送到精确坐标。跨服回家复用 KaProxy 的 Back 模块，无需额外配置。
