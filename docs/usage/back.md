# 返回位置

KaTpa 记录玩家的传送历史和死亡位置，让玩家可以快速返回。

## /back — 返回上次位置

```text
/back
```

执行后传送到上一次传送前或离线前的位置。以下情况会记录上次位置：

* 任何传送（包括其他插件的传送）触发前
* 玩家离线或切换子服时

跨服模式下，如果上次位置在其他子服，KaProxy 会自动切换服务器并传送到精确坐标。

## /dback — 返回死亡位置

```text
/dback
/dback 1
/dback 2
```

不带序号时返回最近一次死亡位置。带序号时返回对应编号的死亡位置，序号从 1 开始，1 为最近一次。

### 死亡位置数量

默认可保存 1 个死亡位置。通过权限插件授予以下权限可增加数量：

| 权限 | 可保存数量 |
| --- | --- |
| `katpa.dback.amount.1` | 1（默认） |
| `katpa.dback.amount.3` | 3 |
| `katpa.dback.amount.5` | 5 |
| `katpa.dback.amount.10` | 10 |

玩家同时持有多个该权限时取最大值。新死亡位置会添加到列表开头；超过上限时自动淘汰最旧的位置。

## 跨服返回

启用 `proxy.enabled` 后，`/back` 和 `/dback` 可以跨服返回。流程如下：

1. 插件读取目标位置所在的子服名称。
2. 如果玩家当前不在目标子服，通过 KaProxy 切换服务器。
3. 玩家到达目标子服后，插件将玩家传送到精确坐标。

跨服返回需要 KaProxy 的 Back 模块已启用。
