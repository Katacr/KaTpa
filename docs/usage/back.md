# 返回位置

KaTpa 记录玩家的传送历史和死亡位置，让玩家可以快速返回。

## /back — 返回上次位置

```text
/back
```

执行后传送到上一次传送前或离线前的位置。以下情况会记录上次位置：

* 任何传送（包括其他插件的传送）触发前
* 玩家离线或切换子服时

跨服模式下，如果上次位置在其他子服，KaProxy 会自动切换服务器并传送到精确坐标。

## /dback — 返回死亡位置

```text
/dback
```

返回最近一次死亡位置（只保留最近一次，与 `/back` 一致）。玩家死亡时会收到一条可点击提示「你的死亡位置位于 … [点击]回到该位置」，点击即可返回，无需手动输入指令。

## 跨服返回

启用 `proxy.enabled` 后，`/back` 和 `/dback` 可以跨服返回。流程如下：

1. 插件读取目标位置所在的子服名称。
2. 如果玩家当前不在目标子服，通过 KaProxy 切换服务器。
3. 玩家到达目标子服后，插件将玩家传送到精确坐标。

跨服返回需要 KaProxy 的 Back 模块已启用。

## 世界黑名单

`config.yml` 的 `modules.back.disabled-worlds` / `modules.dback.disabled-worlds` 可配置**禁止返回的世界名称**（区分大小写，如副本世界）：

- 目标世界在黑名单中时，`/back`、`/dback` 会被拒绝并提示。
- 玩家**处于**黑名单世界时，不会记录 `/back` 位置 / 死亡位置，避免副本结束后残留可返回点位。
