# 首页

> 使用原生对话框、聊天按钮或双击潜行处理玩家之间的传送请求。

**KaTpa** 允许玩家请求传送到他人身边，也可以邀请他人传送到自己身边。玩家无需记住复杂参数：直接输入 `/tpa` 或 `/tpahere` 即可从对话框中选择在线玩家。

## 主要功能

* `/tpa` 请求传送到另一名玩家的位置
* `/tpahere` 邀请另一名玩家传送到自己位置
* 对话框、聊天按钮、双击潜行三种接收方式
* 同时处理来自多名玩家的请求
* 白名单自动同意，黑名单自动拒绝
* 可撤销误发的请求
* 传送倒计时、音效、末影粒子与 ActionBar 提示
* 支持请求冷却、禁用世界和跨世界限制
* 可配合 KaProxy 在不同子服务器之间传送

## 支持环境

| 项目 | 要求 |
| --- | --- |
| Java | Java 21 |
| Paper | 1.21.7 或更高兼容版本 |
| Spigot | 1.21.6 或更高兼容版本 |

推荐使用 Paper，以获得更完整的原生对话框体验。
