# 常见问题

## 输入 `/tpa` 后没有玩家可选

单服模式只显示当前服务器的其他在线玩家。跨服模式还需要 KaProxy 正常运行并开启 Tpa 模块。

## 为什么我不能连续发送请求

服主可能启用了请求冷却，或者你已经有一条尚未处理的请求。等待提示中的秒数，或先使用 `/tpacancel` 撤销旧请求。

## 为什么 `/tpaccept` 打开了列表

你同时收到了多条请求。请选择具体玩家，避免误接受另一条请求。

## 为什么传送被中断

倒计时期间改变位置、受到有效伤害或相关玩家离线都会中断。当前世界被禁用或跨世界传送被关闭时也无法完成传送。

## 白名单和黑名单有什么区别

白名单自动同意对方的请求，黑名单自动拒绝。将玩家加入其中一个名单时，会自动从另一个名单移除。

## 为什么名单里找不到某个离线玩家

该玩家至少需要进入过当前服务器一次，插件才能保存其玩家记录。设置界面的添加按钮默认列出当前在线玩家。

## 为什么修改数据库配置后没有生效

数据库类型和连接信息只在插件启动时读取。修改后请完整重启服务器。

## 为什么会出现 `players.db-wal` 和 `players.db-shm`

KaTpa 默认使用单文件模式，正常情况下只会保留 `players.db`。如果这些临时文件曾被其他工具创建，请先正常关闭服务器再检查；不要在服务器运行时删除数据库文件。

## `/back` 提示没有可返回的位置

如果玩家从未被传送过、从未离线过，或上次位置所在世界已卸载，则无法返回。跨服模式下还需确保 KaProxy 的 Back 模块已启用。

## `/dback` 只能返回一个死亡位置

默认权限 `katpa.dback.amount.1` 只允许保存 1 个死亡位置。在权限插件中授予 `katpa.dback.amount.3` 或更大数值即可增加保存数量。

## 跨服 `/back` 或 `/dback` 失败

请检查：KaProxy 的 Back 模块已启用、`proxy.enabled` 为 `true`、目标子服在线且世界已加载。

## `/warp` 提示余额不足

该地标设置了传送费用，需要安装 Vault 经济插件且账户余额充足。管理员可通过 `/setwarp` 管理对话框调整或取消费用。

## `/sethome` 提示达到数量上限

默认权限 `katpa.home.amount.1` 只允许设置 1 个家。在权限插件中授予 `katpa.home.amount.3` 或更大数值即可增加数量。

## `/warp` 或 `/home` 跨服传送失败

跨服地标和家传送复用 KaProxy 的 Back 模块。请确保 Back 模块已启用、`proxy.enabled` 为 `true`、目标子服在线且世界已加载。

## 如何关闭不需要的功能

在 `plugins/KaTpa/config.yml` 的 `modules` 节点中将对应模块的 `enabled` 设为 `false` 即可。例如关闭地标和家：

```yaml
modules:
  warp:
    enabled: false
  home:
    enabled: false
```

修改后重启服务器。关闭的模块不会注册指令，玩家执行对应指令时会收到"该功能已被管理员关闭"提示。
